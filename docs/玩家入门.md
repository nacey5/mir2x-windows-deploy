# 朋友试玩：先完成一场战斗

适用：mir2x Windows `201b19d`。操作来自该版本源码，当前部署的完整玩法还在验收。本文不包含账号、服务器地址或真实角色数据，请向服主领取测试账号。

## 先认识操作

| 要做什么 | 操作 |
|---|---|
| 移动、撤离追击 | 右键点击能通行的地面 |
| 攻击怪物 | 左键点击怪物 |
| 与人物交谈 | 左键点击 NPC |
| 拾取 | 左键点击地上物品；站在物品处可按 Tab |
| 使用快捷栏物品 | 放入快捷栏后按 1–6 |

别把“背包里有物品”和“已经装备/装入快捷栏”当成一回事。技能也需要先学会并设置对应按键。

## 第一轮怎么玩

1. 查看背包、装备、药品和金币。没有适用武器或没有药时，先找职业引路人，不要直接冲进怪群。
2. 到安全区域附近找一只落单弱怪。点击攻击，观察自己和怪物血量；危险时右键离开，回安全处补给。
3. 击杀后拾取掉落、查看经验变化。回城询问购买药品、出售物品与修理，再开始下一轮。
4. 通过职业任务获得下一个目标。试玩中不要依靠管理员改经验、传送和塞装备来判定正常成长是否顺畅。

若已安装本分支补丁，可在比奇县找万事通（456，393）反复查看上述说明；低于 7 级登录时也会看到提示。没有安装补丁时，该 NPC 的默认脚本为空。

## 本次试玩安排：先用现有版本玩 30–45 分钟

2026-11-06 已启动原安装版本并从客户端画面确认进入比奇县。本轮没有安装开发分支补丁，因此先使用本页说明，不要求玩家去点击尚未安装的比奇万事通指引。已确认进图不代表下表交互都已测通。

| 阶段 | 建议用时 | 操作与完成标准 |
|---|---|---|
| 熟悉操作 | 0–5 分钟 | 右键移动，观察左下角地图坐标；找到背包、装备与技能入口，确认武器已装备 |
| 城内补给 | 5–10 分钟 | 找药店老板（397，363），尝试购买少量金创药；把药放入快捷栏。没有金币或无法交易就记录，不用后台加钱掩盖问题 |
| 第一场战斗 | 10–20 分钟 | 在可通行路线附近寻找落单的鸡，左键攻击；记录怪物血量、击杀、掉落、拾取和经验变化。危险时右键撤离，不进怪群 |
| 回城与任务 | 20–35 分钟 | 回城补给、检查修理；按职业选择下表的引路人，在对应地图尝试接一个任务。跨地图不顺畅就先记录阻塞，不要求首轮跑遍全部地图 |
| 结束检查 | 35–45 分钟 | 在安全处退出客户端再登录，检查装备、背包和任务是否保留。首次不必专门挑战死亡 |

鸡的脚本刷新区域包括比奇县 `(350,350,w=50,h=50)` 和 `(450,350,w=50,h=50)` 等区域，每组 10 只、配置时间 600 秒；这是刷新配置，不保证指定坐标此刻有怪，也不是已验证的寻路路线。先看周围和小地图，找到一只再打。

现有测试角色可能已经配置过装备、经验或金币，适合熟悉操作；数值平衡与新手成长必须另用正常新建角色验证。本轮没有为角色加属性或改库。

## 本机文件入口

当前安装根目录为 `F:\mir`。双击 `1-启动服务器.bat` 后，再双击 `2-开始游戏.bat` 即为已有启动流程。`3-停止服务器.bat` 会强制停止服务端与客户端，试玩中不要随意双击；正常结束先退出客户端。

- `mir2x/client/`：客户端程序、资源和客户端脚本。
- `mir2x/server/`：服务端程序和运行数据；角色数据库为 `mir2x.db3`，不要在运行中手工修改。
- `mir2x/server/script/npc/`：人物对话、商店等脚本。
- `mir2x/server/script/quest/`：职业与其他任务脚本。
- `mir2x/server/script/map/`：地图刷怪等脚本。
- 本开发仓库 `overlays/playability/`：尚未安装到现有服的新手入口补丁。

## 每日有什么可做

已有每日跑腿任务在 7 级开放、每天最多 20 轮。原入口是道馆万事通（398，127）；补丁额外提供比奇万事通入口，复用同一份进度与奖励逻辑。

任务可能派你去其他地图，初次游玩先熟悉路线。每轮奖励随机为金币、经验或补给之一，并非同时全给。忘记目标、重启后找不到任务对话时，回接取入口重新查看。重置按上游服务器时间算法执行，不承诺北京时间零点。

目前没有新增限时活动、签到礼包或活动独立面板。
