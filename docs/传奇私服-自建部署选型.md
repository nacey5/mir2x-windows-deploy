# 传奇（Mir2 / Mir3）自建服务器 —— GitHub 仓库筛选与部署选型

> 调研时间：2026-11-06
> 调研对象：用户给出的 GitHub 搜索页 `https://github.com/search?q=传奇私服&type=repositories` 及其同义检索
> 检索方式：GitHub Search API（仓库名/描述/主题），命中 20+ 关键词，去重后人工过 30 余个仓库；对候选逐个抓 README、目录树、csproj、release 资产做可行性核实
> 结论口径：**只看“能不能真在自己机器/服务器上跑起来”**，不看 star 数

## 0. 一句话结论

**真正适合自己部署的只有 5 个，按“今天就能开服”排序：**

| 排序 | 仓库 | 一句话 | 适用 |
|---|---|---|---|
| ① 最省事 | `etorth/mir2x` | 自带全部美术资源的 C++ 单进程服务端 + 跨平台客户端，预编译包下载即用 | 想 10 分钟内进游戏 |
| ② 中文原味 | `cjlaaa/mir2ServerRelease`（+ `cjlaaa/mir2`） | 现成 `Server.exe`（.NET 4.8）+ 中文 Envir/Maps/数据库，Windows 双击开服 | 就要 1.76 中文经典 |
| ③ 长期维护 | `Suprcode/Crystal` | 1722★ 官方 Crystal 上游，.NET 8，生态最大、教程最多 | 打算长期改版本/开服 |
| ④ Linux 一键 | `asm0x1/CrystalMir2` | 给 Crystal 补了跨平台 `Server.Console` + Docker Compose + 中文语言包 | 有 Linux VPS，想 Docker 化 |
| ⑤ 最原味六进程 | `dwbeta/OpenMir2`（= `mirbeta/OpenMir2`） | DBSrv/LoginSrv/GameSrv + 三网关，经典 M2Server 架构复刻 | 要“原版私服手感”、能折腾 |

## 2. 决定成败的三件事（选型前必须想清楚）

1. **客户端资源**（最大门槛）
   - 原版 Mir2 的 `WZL/WIL` 图像库、地图、音效是 Wemade 版权资产，**没有合法公开下载源**。
   - 只有 `etorth/mir2x` 用自绘/重制资源（`mir2x_assets`），可无争议分发。
   - 其余方案要么从自有老客户端提取，要么用社区 `Crystal.Database` / `mirfiles` 分发（灰色）。
2. **协议私有不通用**
   - Crystal 系、OpenMir2 系、mir2x、GeeM2 彼此**协议不兼容**，客户端必须跟服务端配对。
   - 换句话说：**选服务端 = 同时选定客户端**，不能混搭。
3. **引擎闭源的那一支（GOM/GEE/996/V8/翎风）**
   - 这是国内私服主流，但引擎主程序靠商业授权/私下流通，GitHub 上只有脚本配置。
   - 想走这条线，GitHub 帮不了你“部署”，只能帮你要配置。

## 3. 针对当前这台机器的建议

实测环境：Windows 11 专业版 / 8 线程 / 31.8 GB RAM / F: 154.8 GB 可用 / C: 仅 11 GB
已装：`git 2.33`、`.NET Core 3.1 + Desktop 3.1`（**无 .NET 8**）
未装：`docker`（`docker --version` 不存在）

据此排序：

| 你的目标 | 选它 | 理由 |
|---|---|---|
| 先自己进游戏看看 | **mir2x Windows 包** | 零依赖、零数据库、自带资源，解压双击 |
| 中文 1.76 和朋友联机 | **cjlaaa/mir2ServerRelease** | `Server.exe` 是 .NET 4.8，Win11 自带，双击就开 |
| 长期改版本/做内容 | **Suprcode/Crystal + .NET 8 SDK** | 生态最大；但客户端只能 Windows |
| 有 Linux VPS | **asm0x1/CrystalMir2** | Docker 一条命令；注意 C 盘只剩 11GB，Docker Desktop 别装在 C 盘 |
| 追求原版六进程手感 | **OpenMir2** | 要 MySQL + 补丁 + Delphi 客户端，工作量约 1 天 |

## 4. 可直接执行的部署路径

### 路线 A：mir2x（最快，推荐先跑这个）

```powershell
# 1) 下载 Windows 预编译包（约 1.26 GB，含 client + server 的 install 树）
curl.exe -L -o F:\mir\mir2x-win.zip https://github.com/etorth/mir2x/releases/download/latest/mir2x-windows-build-201b19d.zip
Expand-Archive F:\mir\mir2x-win.zip -DestinationPath F:\mir\mir2x

# 2) 起服务端（单进程，自带 SQLite，无外部依赖）
cd F:\mir\mir2x\install\server
.\server.exe --auto-launch

# 3) 起客户端（另开窗口）
cd F:\mir\mir2x\install\client
.\client.exe --server-ip=127.0.0.1 --auto-login=test:123456
```

Linux 版同理：`mir2x-linux-build-*.zip`（1.27 GB），服务端可跑在 Oracle Cloud always-free 上（作者 wiki 有教程）。

### 路线 B：cjlaaa 中文成品（Windows 最省事）

```powershell
git clone --depth 1 https://github.com/cjlaaa/mir2ServerRelease F:\mir\mir2cn
cd F:\mir\mir2cn
# 需要 .NET Framework 4.8（Win11 自带）；直接运行：
.\Server.exe
# 客户端：cjlaaa/mir2 的 Client 编译产物，或配套中文客户端
# 进 Configs/ 改 IPAddress=0.0.0.0、Port=7000，放行防火墙
```

### 路线 C：Crystal + Docker（Linux VPS）

```bash
git clone https://github.com/asm0x1/CrystalMir2.git && cd CrystalMir2
# 下载数据：https://github.com/Suprcode/Crystal.Database/releases
#   Maps/*.map → Maps/ ; Envir/ → Envir/ ; Configs/ → Configs/
docker compose up -d --build
docker compose logs -f          # 看到 "网络监听中" 即成功
# 端口 7000（游戏）/ 3000（状态）；默认账号 asm0x1/123456
```

上游 Crystal（Windows）：

```powershell
git clone https://github.com/Suprcode/Crystal.git
cd Crystal
dotnet build "Legend of Mir.sln" -c Release   # 需 .NET 8 SDK
# 运行 Server.MirForms\bin\Release\Server.exe，首次启动生成默认配置后关闭
# 再拖入 Crystal.Database 的数据替换
```

### 路线 D：OpenMir2（六进程，Linux 实测版）

启动顺序固定，端口分工：

```
DBSrv(6000/5100/5700) → LoginSrv(5600/5500) → GameSrv(5000)
  → GameGate(7200) → SelGate(7100) → LoginGate(7000 ← 客户端入口)
```

已知坑（来自 2026-10-11 Ubuntu aarch64 实测记录）：

1. headless 崩溃：`Maps.cs` 里 `Console.SetCursorPosition` 无 TTY → 包 `if (!Console.IsOutputRedirected)`；
2. 初始化异常被吞 → 后面必报 `Config为null，请先执行Setup`，别查网络，先找前面被吞的异常；
3. 缺 `DisableTakeOffList.txt` 等 6 个 Envir 列表文件 → 建空文件；
4. `Server.conf` vs `server.conf` 大小写（Linux 敏感），连接串字段名 `ConnctionString` 少个 N 别改；
5. `LoginSrv/ServerAddr.txt`、`DBSrv/AddrTable.txt`、`DBSrv/ServerInfo.txt` 里作者内网 IP 要改成 `127.0.0.1`，否则刷“非法地址连接”；
6. Castle 路径用了 `Envir\\Castle\\List.txt` 反斜杠 → 配置里改 `CastleFile=Castle/List.txt`；
7. MySQL 三库 `mir2 / mir2_account / mir2_db`；
8. 客户端：`mirbeta/MirClient`（Delphi，无官方编译版）或原版 1.76 客户端改 `Mir2.ini` 的 `ServerAddr/ServerPort` + `ServerList.txt`。
