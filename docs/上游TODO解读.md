# 上游 TODO 解读：mir2x 现在缺什么

> 基于 `etorth/mir2x` 仓库根目录 `TODO.md`（2026-11 抓取）+ 本机实测。
> 原文相当长，这里是按「影响什么」重排的摘要。

---

## 一、小任务（作者自己列的）

| 项 | 内容 | 影响 |
|---|---|---|
| NPC 动态化 | NPC 消失、变形、说话，怪物/玩家形象的 NPC | 剧情演出做不了 |
| 魔法命中上报 | 火球/冰球这类飞行魔法，该在**爆炸时**才报命中，不是施法瞬间 | 法术伤害判定不准 |
| 困魔咒空间的破墙 | 可交互的破墙没做 | 该地图走不通 |
| 地图格子触发器 | 语义理解不到位 | 踩点触发类玩法做不了 |
| 怪物/魔法可配置界面 | 现在只能改 Lua / 配置文件 | 调平衡要手改文件 |
| 跟随魔法消失 | 追踪类魔法目标没了要跟着消失 | 会有残留特效 |

这一批都是「已经能跑，但不完整」。

## 二、两条主线任务线：**一个字都没转**

`HonChonDo`（寂幻之刃，25 阶段）和 `HonChonMado`（影魅之刃，11 阶段），31 个文件、约 270 KB。

作者原话是 **"Nothing is converted"**，并且明确说这**不是**像之前 23 个 `MU_*` 技能任务那样抄一遍就行，得先造 6–8 个引擎能力。

### 为什么难：它是一个按真实日历跑的世界事件

`HonChonDo/HonMainControl.txt` 会永远重排自己，按**真实星期几**分支：

```
[@MainHonChonRootin]
DelayGoto [Grobal] 180 @Honchonmadocontrol 1005   -- 每 180 秒重发，永不停止

[@DAYOFWEEKCHECK]
DAYOFWEEK TUE  -> @tuesdayHonQuest
...
```

两个目录里共有 **38 处 `DAYOFWEEK`、144 处 `HOUR`/`MIN`** 时间窗。具体排期举例：

- 周二 23:01–23:05 诺玛仪式刷怪
- 周五 00:01–00:05 法老从围栏移动到遗址，20:55–20:59 再移回去
- 周六 22:55–22:59 法老归位

> 注意：mir2x 已有的游戏内昼夜时钟（1 小时白天 + 1 小时黑夜）**帮不上忙**，那是 2 小时循环，这里要的是真实星期和真实小时。

### 还涉及「世界唯一物品」

`TBL_HonChonMadoSeverFlag`（原作者把 Server 拼成 Sever）是按**单行**存的、不是按玩家：

```
FLD_MADOHAVE=1   →  全世界已经有人持有寂幻之刃
```

拿到剑要做的事包括 `Givew 1 寂幻之刃`（直接进装备栏）、把三个进度字段刷成 7/1/1、`Eventmsg grobal` 全服广播。而且这把剑**只借一周**（阶段 1-22），到期要收回 —— 现有的「按玩家存 `fld_*`」模型表达不了这种共享状态 + 实时过期。

## 三、需要新建的引擎能力

| 能力 | 缺什么 | 用在哪 |
|---|---|---|
| 脚本级 SQL | `ReadValueSql`(118) / `UpdateValueSql`(401) / `WriteValueSql`(3) 全没有 | 两条任务线 + 攻城战（`TBL_SnakeVallyWar` 同样用它） |
| 真实时间调度器 | 星期 + 小时 + 分钟窗口，还要有全服重复 tick | 刷怪排期 |
| 共享（非玩家）任务状态 | 单例 flag + 实时过期 | 世界唯一的剑 |
| `Movenpc` | 运行时把 NPC 挪到另一张地图（39 处调用） | 法老/阿龙怪在围栏与遗址之间搬运 |
| 广播 | `Eventmsg grobal`（全服 + 时长）、`linemsg`（单图） | 剑被拿走时全服喊话 |
| `Mongenp` | 按次覆盖掉落表（`"noitem,..."`） | 事件怪的专属掉落 |
| `ApplyMonEx [Monsterside]` | 给怪物打阵营/称号 | 「毁灭之印大师」这种带称号的怪 |
| `GroupMove` | 整队传送 | 组队进副本 |
| C++ 已有但没绑 Lua | `gainExp`、`setWLItem`（`Givew`）、`mapspell` 防火墙、`Checkweaponlevel` | 直接能用，只是没接出来 |
| `mapting` | 4 个参数，**作者自己也不确定作用** | 待研究 |

## 四、数据缺口

**地图**：`D16061`（用了 43 次，防火墙陷阱和 GroupMove 目标都在这里）、`D16062`（3 次）在 `maprecord.inc` 里**没有记录**，得先确认地图数据是否存在。

**道具**：21 个任务道具里 **15 个不在 `itemrecord.inc`**：

`击退护身符`、`大地石`、`大族长角笛`、`太阳石`、`安息石`、`尸骨项链`、`心石`、`无名书`、`月光石`、`机关零件`、`毁灭之印`、`活石`、`神秘之印`、`藏宝箱`、`青空石`

两把剑本体（影魅之刃、寂幻之刃）是有的。追加到 `itemrecord.inc` 是**ID 安全**的（ID 按位置算，`s_itemRecordAssertor` 会在启动时校验名字唯一），但删除或插入不安全。

**怪物**：`阿龙怪` 既是 NPC（在围栏里）又是怪物（`Mongenp` 刷出来），但**没有怪物记录**，得补。

## 五、数据本身的坑（作者提醒）

- `TBL_HonChonMadoSeverFlag` 的 "Sever" 是原作者的拼写错误，**照着错写**，别"修正"，改了 SQL 就匹配不上
- `HelperHonChonDoBook.txt.utf8` 是一行式的重复文件，没人读它，但会把 `grep -n` 搞乱
- 任务日志里有**两个阶段都标 1-3**（获取宝箱 / 开启宝箱）
- 阶段 1-23 用了 `{FCOLOR/13}`，其它全是 `{FCOLOR/10}`
- `Large D0 13` 超出了日志里 11 个阶段的范围
- 有几处坐标写的是 `(???:???)` 占位符，还有一处 `ApplyMonEx ... "???"`，**原版就是这样发的**

## 六、作者的施工顺序建议

1. 脚本级 SQL（顺手解锁攻城战）
2. 真实时间调度器
3. `Movenpc`，或者干脆砍掉围栏设计，让 NPC 自己在时间窗里说话
4. 广播
5. 补 15 个道具、`阿龙怪` 怪物记录、`D16061`/`D16062` 地图
6. `Mongenp` 掉落覆盖 + `ApplyMonEx` 阵营，然后做刷怪排期
7. **最后**才开始抄对话 —— 先 HonChonDo，因为寂幻之刃是 HonChonMado 的前置

## 七、对「能不能玩」的结论

- **打怪升级**：能玩。比奇县就有 26 种怪，半兽人/狼/毒蜘蛛/食人花都是主动怪，实测能把角色打死。
- **剧情主线**：没有。两条剑任务线一行都没转，玩家没有故事可推进。
- **技能**：`tbl_learnedmagiclist` 是空的，角色出生没有技能，得自己配。
- **任务**：40+ 张 `tbl_questdb_*` 表结构齐全、NPC 也都在，但接任务/交任务没验证过。

要把这服变成「能玩下去」的，优先级应该是：**给角色配初始技能 → 城里补卖装备/药的商人 → 再谈剧情**。
