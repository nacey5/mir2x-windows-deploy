# 新手指引补丁（开发版）

适配上游 `201b19d322b2bf9e5582ea88f5f469d3a4bef29d`。这是现有 NPC 对话界面的内容补丁，不是独立活动窗口或完整新手任务系统。

## 改了什么

- 填充比奇万事通的空脚本：可跳过、可重看的操作说明、第一轮玩法、补给地点、三职业任务起点。
- “今天有什么可做”展示已有每日跑腿规则；7 级起可调用原 `dailyquest.setQuest()`，低等级直接发送接取事件也会被拒绝。
- 新增 `旅途指引.lua`：7 级以下每次登录给一条非阻塞提示。没有持久化已读状态，后续再根据试玩反馈决定是否改为首次提示。
- 不改变原每日奖励、次数上限、重置算法、角色属性和数据库结构。

## 验证与使用边界

已通过 Lua 5.4 下的 10 项测试，使用安装包原 `include/dialog.lua` 生成实际 XML；引擎调用与每日任务服务由测试替身承接。当前安装目录通过只读兼容检查。基准清单内 9 个脚本的 Git blob 均与固定上游提交一致。

原生测试服尝试运行于 `.test-output/runtime`，没有复制现有数据库。客户端首次缺少 `libpinyin`，补齐后进程运行；但工具无法激活、可靠捕获测试窗口，且未取得监听/连服成功证据。已结束本轮创建的测试进程。因此本补丁**未完成原生画面、任务领奖和联网回归**，不可据此宣称试玩验收通过。

## 只读检查

在仓库根使用 Python 3.12：

```powershell
python tools/check_playability.py --server-root '<测试安装目录>\server'
```

返回 `compatible: true` 只表示脚本依赖匹配。目标万事通必须为空文件或与本补丁完全相同；同名新任务不能覆盖其他自定义内容。工具不会启动、停止、复制或修改服务器文件。

## 测试

```powershell
python -m pip install --target .test-deps -r tests/requirements.txt
$env:PYTHONPATH = Join-Path (Get-Location) '.test-deps'
$env:MIR2X_SCRIPT_ROOT = '<原始201b19d安装目录>\server\script'
python -X utf8 -m unittest discover -s tests -v
```

测试只读原脚本，在 `.test-output` 下创建并清理合成目录，不打开游戏数据库。没有原脚本或测试依赖时显式失败，不静默跳过。

## 下一步的安装验收

先使用独立测试服：复制游戏程序、地图、脚本及客户端所需资源，新建测试库；不要复制真实玩家库。将本目录 `server/script` 下两个 Lua 文件按原相对路径放入测试服，保留空 NPC 原件备份。只有原生回归通过后，才安排正式服停服、备份和部署。当前回合没有部署授权，也没有修改原安装目录。

验收路径：新角色登录提示 → 找比奇万事通 → 浏览每个分支 → 6 级接取被拒 → 7 级接取并查看同一任务 → 到目标领奖 → 重复点击不重复领奖 → 重登/重启续接 → 完成 20 轮与跨日重置检查。额外覆盖 800×600 客户区和较大窗口、中文换行、遮挡、关闭后继续移动。

回退脚本层改动时，在停服状态恢复原空 NPC 并移出新增 `旅途指引.lua`。每日跑腿数据沿用上游存储，不应为了回退指引而删除玩家进度。
